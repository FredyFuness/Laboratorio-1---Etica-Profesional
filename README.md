# Historia de la ética — línea de tiempo interactiva

Recurso académico para recorrer la evolución del pensamiento ético, desde la Antigüedad hasta los debates contemporáneos y tecnológicos.

## Contenido y experiencia
- Línea de tiempo con hitos, pensadores y contexto histórico.
- Tarjetas con ideas centrales e imágenes.
- Interfaz con filtrado de elementos y diseño adaptable.
- Bibliografía para consultar las fuentes utilizadas.
- Documento de investigación complementario incluido en el repositorio.

## Tecnologías
HTML, CSS y JavaScript en `index.html`. No utiliza backend ni requiere compilación.

## Ejecutar
```bash
python -m http.server 8000
```
Abre `http://localhost:8000`. También puedes utilizar Live Server.

## Propósito
Presentar una investigación de Ética Profesional de forma visual y navegable. Como ejercicio de desarrollo web, muestra organización de contenido, estilos responsivos e interacción con el DOM.
